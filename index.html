What is a Polygon?

  • A polygon is a closed plane figure made only of straight line sides that do not cross.
  • Each corner is called a vertex (plural: vertices).
  • The number of sides is always equal to the number of vertices.
  • Polygons are named by the number of sides (e.g. triangle, hexagon, 9-gon).

Convex polygon: A polygon which has no interior reflex angles. Every interior angle is less than 180°.
Convex

Convex quadrilateral

4 vertices, all angles less than 180°

Every corner points outwards, so there are no reflex angles.

Non-convex

Non-convex pentagon

5 vertices, one angle over 180°

One interior angle is reflex (between 180° and 360°), which dents the shape inwards.

Another way to test: Every pair of points inside a convex polygon can be joined by a straight line segment which remains inside the polygon.

All line segments between points remain inside the quadrilateral, so the quadrilateral is convex.
